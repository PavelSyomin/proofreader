# Proofreader Legacy

Proofreader is a Joomla component for typos reporting. Legacy version is for Joomla 3 and Joomla 4. It also should work on Joomla 5 with backward compatibility plugin, but as a rule of thumb, consider using [new Proofreader](https://github.com/PavelSyomin/proofreader/) for Joomla 5 as well as for Joomla 4.4 and later.

If you find a bug, please [open an issue](https://github.com/PavelSyomin/proofreader/issues/new/choose). Proofreader Legacy will receive bugfixes but no new features are going to be added.
